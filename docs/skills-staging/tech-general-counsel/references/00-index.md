Read this file first. Then load only the files the phase needs. Everything read stays in context for the session, so do not load all of it for a one-clause question.

## Currency rule

Statutory digests carry a `verified:` date. Anything older than 90 days gets re-searched before it is cited in a document that will publish. Law firm summaries are secondary; where a digest says "verify in statute", do so before relying on the detail.

## What this KB is not

It is not legal advice and it does not replace a Texas-licensed attorney. It exists so the review starts from verified facts and settled decisions instead of from memory, and so counsel receives a clean diff rather than a rewrite.
